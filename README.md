# RUSH CASE

Прототип сайта открытия кейсов CS2: кейсы с рулеткой, апгрейд, контракты, бонусы, профиль и топ игроков.

**Попробовать:** https://senzsenz74-dot.github.io/rush-case/

## Что внутри

- 5 кейсов: «Сифон и Борода», «Оранж», «Альтушка», «Сладкая вата», Premium
- открытие x1–x7, демо-режим, быстрое открытие
- апгрейд из нескольких скинов и баланса, контракты из 3–10 скинов
- ежедневный бонус, промокоды, ранги, топ игроков

## Важно

Это фронтенд-прототип без сервера. Регистрация, баланс и инвентарь хранятся в браузере (localStorage), пополнение и вывод в Steam только имитируются. Для теста: при регистрации начисляется 100 ₽, промокоды `WELCOME`, `RUSH35`, `GLHF`.

## Запуск локально

Откройте `index.html` в браузере — сборка не нужна.
