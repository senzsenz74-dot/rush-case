# RUSH CASE — анимированные баннеры для стримов и TikTok

Новый стиль сайта (тёмное стекло, Oswald, голубой #84d9fd, зелёная кнопка). В кадре: логотип (корона светится, искра), кейсы BLAST / MAJOR / «Всемирная элита», открытие кейса (замок, вспышка), рулетка в **«лупе» как на сайте** с выпадением **★ Karambit | Fade**, промокод **RUSH35 (+35% к пополнению)** — буквы пролистываются как табло, рамка бежит, «+35%» пульсирует. Звук — только в TikTok: звуки сайта (падение кейса, ключ и замок, щелчки ленты, дорогой дроп, щелчки букв), сборка — `src/audio.js`, пересобрать только звук — `node src/render.js tiktok --audio`.

## Как стримеру поставить плашку в OBS
1. OBS → «Источники» → **+** → **«Медиаисточник»** (Media Source) → назвать «RUSH CASE».
2. Галочка **«Локальный файл»** → выбрать `RUSHCASE_stream_plashka_1600x330.webm`.
3. Галочка **«Повтор»** (Loop). Остальное не трогать → ОК.
4. Перетащить плашку вниз экрана (на сцене 1920×1080 она встаёт по ширине с отступами). Фон прозрачный — игра видна вокруг.
5. Значок в углу — так же, файл `RUSHCASE_stream_corner_520x470.webm`, уменьшить до нужного размера мышкой.

Twitch Studio, Streamlabs, vMix — тоже «медиа/видео-источник» с повтором. Если программа не понимает прозрачность webm — сообщить, сделаем вариант .mov.

## Как пересобрать (если поменять промокод, нож, тексты)
Тексты и промокод — в начале `src/banner.js` (`PROMO`, `CASES`, `KNIFE`); тайминги — в функциях `buildStream`, `buildCorner`, `buildShort`.
```
cd promo-banners
node src/render.js            # все форматы (~5 мин)
node src/render.js tiktok     # один формат
node src/render.js --shots    # только контрольные кадры в output/shots/
```
Нужны Google Chrome и модули `puppeteer-core`, `ffmpeg-static`, `sharp` (берутся из `promo-video/node_modules`, или `npm i puppeteer-core ffmpeg-static sharp` здесь).
Живой просмотр в браузере: открыть `src/banner.html?f=stream` (или `corner`, `tiktok`, `square`; `&check=1` — шахматка под прозрачностью, `&t=7.2` — стоп-кадр).

## 3D-кейс (TikTok и квадрат)
MAJOR открывается настоящей 3D-моделью сайта (`assets/cs2case/case-major2.glb`, анимация ключом из Blender) со светом 3D-сцены сайта. three.js — в `src/vendor/three/`. Для живого просмотра 3D страницу нужно открывать через сервер (например `node tools/serve.js` из корня сайта → `http://localhost:5178/promo-banners/src/banner.html?f=tiktok`), с диска (file://) 3D не грузится — тогда кейс просто вздрагивает. `src/render.js` поднимает сервер сам.

## Откуда что
- Логотип, кейсы, скины рулетки — из `assets/` сайта (`src/items.js` создаёт `src/pick-items.js` из `js/skins.js`).
- Нож — картинка Steam (`src/img/karambit.png`, обрезана и увеличена ×2).
- Шрифт Oswald — `src/fonts/` (кириллица + латиница).
- Папка на сайт не выкладывается (deploy.yml копирует только index.html, assets, css, js).
