# RUSH CASE — рекламный ролик 9:16

Вертикальный ролик 1080×1920, 30 к/с, 20 с: реальный сайт RUSH CASE (десктопный дизайн) в «парящих» 3D-панелях на фирменном фоне + звуковые эффекты сайта и монтажа. Голос и музыка — накладываются отдельно (`script.md`).

## Файлы
- `site-audit.md` — какие функции работают и что можно показывать
- `storyboard.md` — раскадровка с таймкодами · `script.md` — текст диктора
- `src/config.js` — тайминг сцен, подписи, финальный текст и адрес
- `src/capture.js` — покадровая съёмка сайта в «виртуальном времени» (сервер подменён заглушкой, деньги не тратятся)
- `src/compose.html`, `src/compose-scene.js`, `src/compose.js` — композиция 9:16 (панели в 3D, золотая пыль, хук, финал)
- `src/audio.js` — звуковая дорожка: звуки сайта тем же кодом сайта в тех же кадрах + синтез переходов и ударов → `assets/sfx.wav`
- `src/build.js` — сборка MP4, превью и субтитров
- `output/` — `RUSH_CASE_vertical_18s.mp4`, `RUSH_CASE_poster.png`, `RUSH_CASE_subtitles.srt`

## Повторный рендер
Нужны Node.js 18+ и Google Chrome (путь — `CHROME_PATH`, по умолчанию стандартный путь Windows).
```
cd promo-video
npm install
node src/build.js all
```
`all` = съёмка (~5 мин) → композиция (~5 мин) → звук → видео. Без `all` — только сборка видео из готовых кадров и звука.
Отдельные сцены пересъёмки: `node src/capture.js open upgrade`. Промежуточные кадры лежат в `.frames/` (в .gitignore).

## Важно
- Сайт не меняется: код берётся как есть, для съёмки он только «открывается» в памяти (доступ к звуковому движку и данным).
- Выпадение кейса — по реальным шансам кейса с фиксированным зерном (`DROP_SEED`), не подобрано вручную.
- Сцена вывода в Steam — по решению заказчика; публиковать после запуска реального вывода, подпись — по факту (`CAPTIONS.withdraw`).
- Файл назван «18s» по ТЗ; фактическая длина 20 с (допустимо 15–20) — чтобы показать вывод и турниры.
