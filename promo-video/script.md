# Текст диктора (для озвучки, которую наложат позже)

Ролик смонтирован без голоса и музыки — только звуковые эффекты. Тайминги реплик под текущий монтаж:

| Время | Реплика |
|---|---|
| 0:00–1:60 | «Готов к открытию?» |
| 1:90–3:80 | «Выбирай кейс на RUSH CASE». |
| 4:10–9:20 | «Запускай рулетку и следи за моментом дропа». (результат на 9:27) |
| 11:00–15:40 | «Исследуй апгрейды и контракты». |
| 15:60–17:60 | «Выводи скины в Steam». *(формулировку про скорость — по факту работы вывода)* |
| 17:80–19:20 | «Играй турниры CS2». |
| 19:40–22:20 | «Переходи на сайт и попробуй открыть первый кейс». |

Голос: русский, уверенный, без крика; чётко произносить «RUSH CASE». Музыку при сведении приглушать под голос, эффекты (`assets/sfx.wav`) — третьим слоем.
