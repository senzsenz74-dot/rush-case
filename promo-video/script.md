# Текст диктора (для озвучки, которую наложат позже)

Ролик смонтирован без голоса и музыки — только звуковые эффекты. Тайминги реплик под текущий монтаж:

| Время | Реплика |
|---|---|
| 0:00–1:60 | «Готов к открытию?» |
| 1:80–3:40 | «Выбирай кейс на RUSH CASE». |
| 3:80–8:80 | «Запускай рулетку и следи за моментом дропа». (пауза на результате 8:87) |
| 10:20–13:20 | «Исследуй апгрейды и контракты». |
| 13:40–15:20 | «Выводи скины в Steam». *(формулировку про скорость — по факту работы вывода)* |
| 15:40–16:60 | «Играй турниры CS2». |
| 16:80–19:60 | «Переходи на сайт и попробуй открыть первый кейс». |

Голос: русский, уверенный, без крика; чётко произносить «RUSH CASE». Музыку при сведении приглушать под голос, эффекты (`assets/sfx.wav`) — третьим слоем.
