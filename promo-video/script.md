# Текст диктора (для озвучки, которую наложат позже)

| Время | Реплика |
|---|---|
| 0:00–1:60 | «Готов к открытию?» |
| 1:90–3:70 | «Выбирай кейс на RUSH CASE». |
| 3:90–7:20 | «Запускай рулетку и лови момент дропа». (результат на 7:30) |
| 9:00–11:90 | «Апгрейди скины до легенды». |
| 12:10–18:30 | «Подписывай контракты и забирай новый скин». |
| 18:60–20:40 | «Выводи скины в Steam». *(про скорость — по факту работы вывода)* |
| 20:60–23:60 | «Забирай бонус каждый день». |
| 23:90–29:00 | «Собери команду и позови друзей». |
| 29:30–35:40 | «Играй турниры CS2 и забирай призы». |
| 35:70–40:40 | «Переходи на сайт: промокод WELCOME и сто рублей за регистрацию». |

Голос: русский, уверенный, без крика; чётко произносить «RUSH CASE». Музыку при сведении приглушать под голос, эффекты (`assets/sfx.wav`) — третьим слоем.
