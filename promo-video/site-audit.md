# RUSH CASE — аудит функций для рекламного ролика

Дата: 27.10.2026. Источник: опубликованный сайт https://senzsenz74-dot.github.io/rush-case/, код репозитория (`js/app.js`, `supabase/*.sql`), журнал `ЖУРНАЛ.md`, проверки в браузере (puppeteer) и на копии базы (PGlite).

Статусы: **Работает** — реальное действие на сервере · **Демо** — интерфейс работает, но экономической операции нет · **Не завершено** — интерфейс есть, функция не подключена · **Нет доступа**.

| Функция | Статус | Как проверено |
|---|---|---|
| Главная, баннеры, каталог кейсов | Работает | Сайт открывается, 15 кейсов, слайдер баннеров; скриншоты ПК/телефон |
| Страница кейса, открытие x1–x7, рулетка, результат | Работает | Выпадение считает сервер (`open_case`, supabase/server.sql) по шансам кейса; проверено 10 500 открытий на копии базы — распределение совпадает с шансами. В ролике — реальная анимация сайта, ответ сервера подставлен локально (без списания денег) |
| Демо-открытие | Демо | Кнопка «Демо»: предмет не начисляется; шансы в демо завышены (минимум x2) — в ролике **не используется** |
| Апгрейд | Работает | Сервер `upgrade` (шанс = 92% / икс, максимум 75%); свои множители сохраняются в аккаунте |
| Контракты | Работает | Сервер `contract` (пул 0,25–4× суммы, отдача ~90%) |
| Бонусы, промокоды | Работает | `claim_daily`, `use_promo`, `claim_social` на сервере |
| Профиль, инвентарь, R-COIN, топ игроков | Работает | Профиль и инвентарь в базе; топ — серверная функция `top_players` по реальным дропам |
| Вход через Steam | Работает | Функция `steam-auth` (OpenID + проверка у Steam), проверены реальные входы |
| Турниры CS2 (этап 1) | Работает | Команды, приглашения, регистрация; SQL `tournaments.sql` запущен на сервере. Сетка и страница матча — в разработке |
| Пополнение баланса | Не завершено | Касса не подключена: заявка в поддержку, баланс начисляет админ. **В ролике не показывается** |
| **Вывод скинов в Steam** | **Не завершено** | Сейчас кнопка меняет статус предмета, в Steam ничего не отправляется. Подключение Lis-Skins — по графику. **Сцена вывода в ролике есть по решению заказчика; ролик публикуется только после запуска реального вывода, формулировку скорости — по фактическому замеру (`WITHDRAW_CAPTION` в `src/config.js`)** |

## Что показано в ролике
Каталог → открытие кейса (рулетка и результат) → апгрейд → контракт → вывод в Steam (см. оговорку выше) → турниры → призыв перейти на сайт.

## Чего в ролике нет
Пополнения, обещаний заработка, гарантий редкого дропа, счётчиков онлайна и отзывов.
